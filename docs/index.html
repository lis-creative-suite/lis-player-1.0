LIS PLAYER

Один плеер. Файлы остаются на этом компьютере.

Windows Android

Установка

Windows ставится для текущего пользователя. Если система пишет «Защитила компьютер», откройте «Подробнее» и «Выполнить в любом случае». Уже установленную копию можно обновить на месте: библиотека при этом не удаляется.

Телефон — один APK, Android 10 и новее. В нём аудио, видео, фото и документы. Музыка играет с выключенным экраном.

На компьютере LIS PLAYER открывает аудио, видео и картинки. Документы открывает LIS_DOC, если он установлен отдельно.

Воспроизведение

Двойной щелчок по файлу открывает его в плеере. Песня с холодного запуска — узкая полоса внизу. Видео и картинка — большое окно.

  • Пробел — пуск и пауза.
  • Стрелки влево и вправо — предыдущий и следующий.
  • Вверх и вниз — громкость.
  • F — кинозал.
  • Esc прячет плеер в трей, Shift+Esc возвращает его.

Библиотека

Папка Документы\LIS_Player_Library. Полки по формату: Audio, Video, Images. Скриншоты лежат в Images\Screenshots.

Разложить переносит файлы внутри библиотеки. Сначала полка по формату, затем папка с тем же именем, из которой файл пришёл. Файл с рабочего стола или из загрузок попадает в папку месяца, например 2026-11. Скриншоты собираются в Images\Screenshots. Папка Creative Suite не перекладывается.

Формат и Папка только меняют порядок показа. Файлы на диске от этого не двигаются. Повторное нажатие возвращает порядок по имени.

Отправка в библиотеку по умолчанию копирует файл. Перманентный режим в настройках переносит его. Удержание кнопки библиотеки две секунды раскладывает текущий файл или папку по тем же правилам.

Обновление

Если вышла новая версия, в шапке появляется метка. Обновить ставит её и не стирает библиотеку. Не сейчас скрывает эту версию.
